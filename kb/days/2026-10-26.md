### [How I Found a $113,337 AF_ALG Linux Local Privilege Escalation Before Copy Fail](https://starlabs.sg/blog/2026/09-how-i-found-a-113337-af_alg-linux-local-privilege-escalation-before-copy-fail) — 7/10

Notes: CVE-2025-39964, found by Muhammad Alifa Ramdhan at STAR Labs with Billy (Bing-Jhong) Jheng completing the chain, earned $113,337 as a Google kernelCTF submission; reported as the first kernelCTF entry using AF_ALG as the entry point. · Distinct from the 2026 Copy Fail bug (a straight-line AEAD logic flaw): this is a race between two threads calling sendmsg() on the same AF_ALG socket, where lock_sock() is released during af_alg_wait_for_wmem() via sk_wait_event(), letting thread B resume into state thread A changed. · The interleaving plus a deliberately failing memcpy_from_msg() (invalid user address) forces ctx->merge==true while the final af_alg_tsgl has cur==0, so sg = sgl->sg + sgl->cur - 1 computes sg[-1], an out-of-bounds read of a fake scatterlist 8 bytes before the 4096-byte object. · Heap spray fills the preceding object's last 8 bytes (offset 0xff8) to control sg[-1].page_link, which feeds page_address(sg_page(sg)) + sg->offset + sg->length as the memcpy_from_msg() destination, turning an OOB read into a kernel write primitive. · memcpy_from_msg() routes through copy_from_iter_full() to raw_copy_from_user(), whose exception handling returns bytes-uncopied instead of oopsing on an unmapped destination; sendmsg() returning 1 vs -EFAULT becomes a non-crashing oracle to defeat KASLR and locate the target page. · The write overwrites core_pattern with a pipe (|) command pointing at the exploit binary; crashing a child makes the kernel run it as root core-dump handler. ### [Groupwise Agentic Grading and Advantage Redistribution for Code Agent RL](https://arxiv.org/abs/2609.32577) — 6/10

If you train code agents with GRPO and binary test rewards, every passing trajectory gets the same advantage, so the policy never learns to prefer clean, in-scope fixes; GAGAR adds a grader that reranks and reweights those passes.

Notes: The problem: with executable tests giving binary rewards, GRPO assigns identical advantages to all test-passing trajectories in a rollout group, giving no signal to favor targeted implementations over ones with unnecessary or out-of-scope changes. · Mechanism: an SFT-trained agentic grader inspects all trajectories from a group placed in a shared workspace and ranks the test-passing candidates by implementation quality. · Redistribution is sum-preserving: lower-ranked passing trajectories are downweighted, then all passing advantages are rescaled proportionally to restore the group's original advantage sum, shifting credit toward higher-quality passes without changing the total. · Built on dynamic sampling that retains only groups containing both passing and failing trajectories. · Evaluated on pre-RL SFT checkpoints of MiMo-V2.6-Flash (310B total params) and MiMo-V2.6-Pro (1.02T total params); claimed results are improved code-agent performance, reduced trajectory-length growth, and more stable training. · Caveats: gains are self-reported with no public benchmark numbers, baselines, or ablations in the abstract; the grader itself is a trained model whose ranking quality is unverified here.
