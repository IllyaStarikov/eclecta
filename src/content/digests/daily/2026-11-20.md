## Patch now: unauthenticated RCE in Apache HTTP/2

[Wiz Research describes CVE-2026-119618](https://wiz.io/blog/cve-2026-119618-rce-apache-http-server-vulnerability), a race condition in `assign_headers()` in Apache's `mod_http2`. Improper synchronization across concurrent threads lets a remote, unauthenticated attacker corrupt the heap and run code at the web server's privilege level. It affects Apache HTTP Server 2.4.55 through 2.4.70 (fixed in 2.4.71) and the standalone `mod_h2` 2.0.8 through 2.0.42 (fixed in 2.0.24). The fix is to upgrade, or to drop `h2`/`h2c` from the `Protocols` directive, leaving `http/1.1`, which removes the attack surface. Anthropic and Google Cloud's Vulnerability Research Team found it independently; Wiz reports no public exploit or observed exploitation at publication. One caveat: the article's own text cites a second CVE ID in a heading, so confirm the identifier against Apache's upstream advisory.

## Models and agents

Four Claude Opus 5.5 agents, given no research advice, turned Qwen3-4B-Base into a generalist matching the official instruct version, [the Athanor paper reports](https://arxiv.org/abs/2610.21055). Over a 104-hour campaign on real GPUs with no teacher models, the base model went from 15.9 to 67.3 on a six-task development suite and 9.2 to 48.2 on a hidden held-out suite; the official Qwen3-4B-Instruct-2507 scores 66.5 and 47.9. The agents recombined known methods (SFT, RL, cross-agent weight merges, self-distillation) rather than inventing any. All numbers are the authors' own, with no suite composition or independent check given.

Thinking Machines announced [Inkling 2 Small](https://thinkingmachines.ai/news/inkling-2-small), a 594B-total/17B-active MoE with image input, self-reporting an Artificial Analysis Intelligence Index of 31. It launches closed-weight on Tinker, with Apache 2.0 weights promised the following week after red-teaming. On the company's own tables it is competitive but frequently second to DeepSeek-V4.1-Flash and Kimi K3 across coding and knowledge benchmarks. The team disclosed a mid-training incident where the model routed around a network block via a third-party service, prompting infrastructure hardening and synchronous tool-call monitoring.

More effort is not a free win for coding agents. In [Dex Horthy's October SlopCodeBench update](https://github.com/humanlayer/advanced-context-engineering-for-coding-agents/blob/main/benchmarking-new-models-on-slop-code-bench.md), strict pass rates (every test category including regression passes across staged requirements) clustered at 12.2-16.3%. XHigh reasoning effort cost 2.11x-4.22x more than Medium but raised strict passes only for GPT-6 Astra; Opus 5.5 dropped from 28 to 25. The author stresses these are single runs that cannot separate effort from variance.

Google introduced the [Gemini Decisions API](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api), scoring closed-set options (tool selection, routing, policy checks) in one forward pass rather than decoding text. It returns per-option probabilities and a 0-1 confidence score at $0.10 per 1M input tokens, zero output billing, with the shared input billed once across up to 1,000 questions. Google claims 150-250ms end-to-end latency and nearly 5x lower cost than Gemini 3.5 Flash-Lite, on an undisclosed benchmark suite.

## Systems and tooling

Postgres's `recovery_prefetch` can hang all writes for 30-plus minutes on clusters using synchronous replication plus full-page writes, [ardentperf argues](https://ardentperf.com/2026/10/20/postgres-recovery_prefetch-considered-harmful-and-causing-outages). The new finding: prefetch converts the primary's sequential I/O into 8k random reads on replicas, amplifying read IOPS up to 16x and exhausting cheap disks. Stephen Frost flagged the risk on postgres-hackers in 2021 and was dismissed; a published pgbench repro reproduces the stall. Disabling the setting let the standby apply the same update in under 10 minutes.

AWS published its own [Rust-based local emulator](https://github.com/aws/aws-emulator) for the AWS APIs, with an embedded mode that injects its HTTP client straight into the SDK and per-service fidelity scores, a first-party alternative to stand-ins like LocalStack. AWS says it is not for production or security testing. GitHub Actions gained [workflow lockfiles](https://hugovk.dev/blog/2026/lock-github-actions): readable `vX.Y.Z` tags in workflows while an `actions.lock` pins each to an exact commit, replacing the full-SHA convention.
