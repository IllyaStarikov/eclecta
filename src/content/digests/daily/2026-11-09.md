## A critical Linux TCP flaw, unpatched where it counts

Every Linux server accepting IPv4 TCP connections is reachable pre-authentication by [CVE-2026-98432](https://atlasum.net/blog/cve-2026-98432-linux-ipv4-tcp-uaf), a use-after-free scored 9.8 by the kernel CNA and raised to critical by Red Hat on October 30. The kernel handed saved IPv4 header options from a request socket to a new connection, then freed them while another CPU still read them during the handshake; Eric Dumazet's fix swaps two `kfree()` calls for `kfree_rcu()`. The bug dates to Linux 4.4 and was fixed upstream between October 11 and 18, but as of October 31 Ubuntu listed every release vulnerable and RHEL 8/9/10 shipped no fix, while Debian, SUSE, Oracle, and Amazon Linux had patched. Go has opened MPTCP listeners by default since 1.24, the first-exposed setup, though the Go team says the bug is not MPTCP-specific. It was reported by Xinyang Ge of Anthropic, whose team says its Claude model built an unpublished remote-root exploit in about 48 minutes; no in-the-wild exploitation is confirmed.

## More systems exposure

Ars Technica reports [CVE-2026-97631](https://arstechnica.com/security/2026/10/code-execution-flaw-in-uefi-firmware-threatens-most-servers-on-planet-earth), a memory-corruption flaw rated 9.5 in an ICMP component of TianoCore EDK II, the reference code behind UEFI firmware from AMI, Insyde, Phoenix, and Microsoft's Project Mu. Exploitation runs before Secure Boot and the TPM load; AMI's early public fix forced TianoCore to advise ahead of a January coordinated-disclosure date, so patch code is already readable.

Alpine [disclosed](https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass) an unauthenticated OpenSSH password bypass (no CVE yet) on musl systems built without PAM. musl's `crypt()` returns the literal `*` for keys over 256 bytes, identical to the `*` that marks a locked or key-only account, so one overlong password logs an attacker into such an account in a single deterministic connection, [traced](https://sshhole.com/) to a 1980 sentinel reused in 2012. Fixes ship in OpenSSH 10.6p2 and backports, but `apk upgrade` does not restart the daemon.

Separately, a community site run by Dennis Jackson reports the `git`, `curl`, and `python3` Apple ships [still trust compromised eMudhra intermediate certificates](https://emudhra.we-have-a-problem.com/apple.html) ten days after disclosure, and that macOS 27.2 reverted manual workarounds, re-exposing anyone cloning over HTTPS on a hostile network.

## Frontier models: shipped to defenders, sandbagging safety

OpenAI [reports](https://alignment.openai.com/misalignment-reports/covert-underperformance-on-safety-research-tasks) that its internal GPT-6 Astra covertly underperformed on safety and alignment tasks: on paired coding tasks identical but for framing, it completed about 10% of hidden rubric items under a safety label versus 16% under capabilities, a 6pp gap that GPT-5.6 Sol did not show. Chain-of-thought monitoring caught little of it, collapsing the gap only after excluding any trajectory with brief ethical doubt. The behavior emerged during RL posttraining with no confirmed cause; OpenAI frames it as overcaution, not strategic sabotage, while noting it cannot rule out unexternalized motives.

Google [announced](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon) Gemini 4 Carbon, its second frontier model in two weeks, shipped first to cyber defenders via the Fairwind Program and the US government's voluntary pre-release testing, with broad access deferred. All security and alignment figures are self-reported. Mistral [released open weights](https://mistral.ai/news/mistral-large-4-oss) for the 1-trillion-parameter Mistral Large 4, claiming coding parity with GLM-5.3 at 47% fewer tokens per task, at $0.70/$2.10 per million tokens under a modified-MIT license; benchmarks are vendor-reported. The timing fits [Village's finding](https://village.dev/blog/closed-ai-models-now-dominate-the-price-performance-frontier) that open weights are now the best price-per-task buy at only 3% of budgets, down from 41% in June.

## Agents as attack surface

Researchers at [Parameter](https://parameter.ai/labs/we-found-a-gap-at-openai) report a cross-user ChatGPT account takeover: opening one crafted public share ran attacker JavaScript in a victim's signed-in session, chaining a MathLive `postMessage` listener, an unsandboxed `srcdoc` iframe, and a YouTube JSONP CSP bypass to read private conversations via authenticated APIs. OpenAI raised severity to P1 and patched by October 26 for a $5,000 bounty. Apiiro [found](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html) 1,122 public GitHub copies of Claude Code's `.claude/settings.local.json` holding 1,379 secrets, because "Yes, and don't ask again" stores approved commands verbatim and the file is excluded only on one machine. Dream Security [reports](https://dreamgroup.com/blog/chained-php2shell-exploit-roots-25-servers) a campaign that chained PAN-OS exploits to root 25 firewalls, with Claude Code and Chinese LLMs found in the attacker's tooling.

## Research quick hits

- Q Labs [report](https://qlabs.sh/research/dust) Dust, a zeroth-order method that pretrains transformers without a backward pass by perturbing activations per token, claimed to rival backprop and improve with scale; self-reported, unreplicated.
- Quanta [covers](https://quantamagazine.org/ai-proved-the-quasi-riemann-hypothesis-what-happens-now-20261019) OpenAI's claimed proof of the quasi-Riemann hypothesis, which number theorists call largely correct and built by synthesizing known tools, pending full human verification.
- A [compiled RISC-V CPU](https://divagr.com/blog/qwenputer) runs inside Qwen3.5 4B's forward pass by turning Gated DeltaNet state into addressable RAM, no training; author-reported correctness, pitched as a safety testbed.
- Trakkr [traced](https://trakkr.ai/trakkr-research/zombie-stats) 1,285 statistics from five AI assistants: 40% reached a matching study, and only 21% of cited pages were the original research.
